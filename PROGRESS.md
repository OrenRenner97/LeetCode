# Прогресс

| # | Задача | Сложность | Тема | Лучшее решение | Бизнес-кейс | Лучший ускоритель |
|---|--------|-----------|------|----------------|-------------|-------------------|
| 1 | [Two Sum](problems/0001_two_sum) | Easy | Hash Table | hash one-pass O(n)/O(n) | сверка платежей | numba prange (batch), GPU от 10⁵ (single) |
| 2 | [Add Two Numbers](problems/0002_add_two_numbers) | Medium | Linked List, Math | итеративно с переносом O(max(m,n)) → `algos.add_digits` | uint256-леджер токена (crypto) | numba: carry-select (сложение), carry-save (аудит ×4300) |
| 3 | [Longest Substring Without Repeating Characters](problems/0003_longest_substring_without_repeating_characters) | Medium | Sliding Window, Hash Table | окно с прыжком по последней позиции, O(n) → `algos.longest_unique_window` | антифрод: перебор украденных карт (fintech) | numba prange по источникам (×17–51), потоковый детектор 430k/с |
| 4 | [Median of Two Sorted Arrays](problems/0004_median_of_two_sorted_arrays) | Hard | Binary Search | разрез короткого массива O(log min(m,n)) → `algos.median_of_sorted` (с помощью Cursor, перерешать 2026-11-02) | справедливая цена по площадкам (fintech) | numba для разреза (×3), C для K шардов (×6–12); бизнесу не нужен |
| 5 | [Longest Palindromic Substring](problems/0005_longest_palindromic_substring) | Medium | String, DP, Two Pointers | перебор Θ(n³); лучшие — расширение от центра O(n²) и Manacher O(n) → `algos.longest_palindrome` | рестрикционный анализ ДНК и праймеры (biotech) | numba/C ×25–35 на геномах; `find_sites` ×10 после правок бизнес-слоя (Амдал) |
| 6 | [Zigzag Conversion](problems/0006_zigzag_conversion) | Medium | String, Simulation | симуляция в dict строк, `+=` даёт O(n²/r); лучшее — срезы с шагом 2(r − 1) → `algos.zigzag_encode` (гибрид: по строкам / по периодам) | шифр «изгородь»: задания и взлом без ключа (edtech) | не делали: только Python |
| 7 | [Reverse Integer](problems/0007_reverse_integer) | Medium | Math | строка + `bit_length` (64-битное промежуточное); лучшее — StrLexCompare: сравнение строк, без больших int → `algos.reverse_digits` | развёрнутые ключи строк против hotspot'а (infra) | не делали: только Python |
| 8 | [String to Integer (atoi)](problems/0008_string_to_integer_atoi) | Medium | String | один цикл с флагами `sign`/`has_number`; фазы склеены, `isdigit` пропускает Unicode-цифры; лучшее — Regex (×2.4), честное — PhasesGuard (стоп у границы) → `algos.parse_int_prefix` | аудит числовых env: atoi против int() (infra) | не делали: только Python |
| 9 | [Palindrome Number](problems/0009_palindrome_number) | Easy | Math | `str(x) == str(x)[::-1]`; лучшее — StrOnce (`x < 0` сразу, ×1.7), без строк — HalfReverse → `algos.arithmetic.is_digit_palindrome` (+ `width`, `next`/`prev_digit_palindrome`) | не делали: слишком простая | не делали: только Python |
| 10 | [Regular Expression Matching](problems/0010_regular_expression_matching) | Hard | String, DP, Recursion | рекурсия + `@cache` O(m·n) (идея своя, реализация с помощью Cursor); лучшее — TokenNFA (НКА Томпсона); `re.fullmatch` экспоненциален (ReDoS: 30 s на 25 символах) → `algos.is_match` (НКА на битовой маске, ×33 к `set` на adversarial) | сценарии мошенничества в сессиях: ATO, правила без ReDoS (fintech) | не делали: линейно алгоритмом, узкое место — объекты событий |
| 11 | [Container With Most Water](problems/0011_container_with_most_water) | Medium | Two Pointers, Greedy | два указателя O(n), но `max`/`min` в цикле; лучшее — TwoPointersSkip (пропуск низких линий, ×5–9); numpy-сортировка по высоте ×2–6 при O(n log n) → `algos.max_container` | не делали | не делали: ~7 ms на 10⁵, узкое место — валидация |
| 12 | [Integer to Roman](problems/0012_integer_to_roman) | Medium | Hash Table, Math, String | жадно по 13 номиналам, но поиск с начала таблицы после каждого символа; лучшее — DigitTables (×10, 4 таблицы по разрядам), FullLookup (×57, все 3999 ответов заранее) → `algos.to_roman` (вне 1..3999 → `None`) | не делали: слишком простая | не делали: O(1) по таблице |
